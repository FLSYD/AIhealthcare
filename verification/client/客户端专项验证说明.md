## 定位

本目录用 Node 内置 `node:test`、`node:assert/strict` 和 `node:vm` 加载当前仓库中的真实小程序页面与工具源码。测试只 mock `wx`、`Page`、`App`、业务 API、鉴权结果和 `wx.request` 边界，不发送真实后端请求，不执行真实支付，也不修改业务代码。

通过专项测试表示当前缺陷已被稳定复现，或既有正常防护已得到验证。复现通过不等于业务无缺陷；最终缺陷判断仍以审查报告和实际业务修复验收为准。

## 运行

在本目录直接运行：

```powershell
node --test
```

也可从 `D:/cxdownload/AIhealthcare` 运行：

```powershell
node --test verification\client\client-state-regressions.test.cjs
```

无需新增 npm 依赖，不需要启动后端、MySQL 或微信开发者工具。
