## 启动约束

- 后端端口 `18080`，管理前端端口 `15173`，都默认只监听本机回环地址。
- 后端在客户端创建前检查最终配置，拒绝旧库、root 账号、其他 Redis 端口以及 URL / 集群 / Sentinel 等替代连接配置。
- 前端代理固定 `127.0.0.1:18080`，拒绝旧后端或其他地址覆盖。
- Redis 启动前检查端口、监听地址、密码与数据目录，拒绝指向其他实例的配置。
- 监督进程持有文件独占锁，避免多个窗口同时启动。已占用端口不会被复用，也不会被停止。
- Windows Job 与放行门确保只管理本次创建的服务进程，关闭窗口后回收其子进程；本机 MySQL80 不纳入该进程组。
