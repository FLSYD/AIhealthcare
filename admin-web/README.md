# AIhealthcare 管理端

基于 Vue 3、Vite 和 Element Plus 的医院预约挂号管理界面。管理端通过同源 `/api` 和 `/uploads` 代理访问后端，源码位于仓库的 `admin-web/` 目录。

## 本地启动

需要 Node.js 20.19 及以上或 22.12 及以上。首次安装从仓库根目录执行：

```powershell
Set-Location .\admin-web
npm ci
npm run dev
```

开发服务器默认监听 `127.0.0.1:15173`，访问 `http://127.0.0.1:15173/login`。后端默认地址为 `http://127.0.0.1:18080`。

需要同时启动 Redis、后端、管理端和局域网转发时，在仓库根目录运行：

```powershell
.\一键启动.cmd
```

启动窗口会显示本次可用的本机和局域网地址。局域网 IPv4 由启动器动态检测，不应在文档或源码中写死固定网段。

## 功能与角色

- 管理员：数据概览、科室、医生与配药师档案、单次及批量排班、药品、用户、日志、菜单和预约管理。
- 医生：工作概览、本人排班与预约，接诊、病历、开处方，以及无需处方时完成就诊；患者缴费后由配药师发药。
- 配药师：配药工作台与只读药品信息，查看已付款处方、核对药品明细、发药并查看已发药记录。
- 所有后台角色：个人信息、头像、修改密码和消息通知；患者账号不能登录后台。

菜单与路由均由后端权限信息约束。医生和配药师人员档案会同步对应账号；角色、科室和人员档案绑定的修改仍受后端接口校验。

通过人员档案新建的医生、配药师，初始密码保持为 `123`，员工可在个人信息页面自行修改。首次安装创建的后台 `admin` 密码由初始化脚本单独设置，不会重置既有账号。

配药师账号支持单独删除和批量逻辑删除。删除操作按后端逻辑删除语义执行，页面应在完成后刷新用户列表，并以服务器返回结果为准。

批量排班一次最多选择 5 个日期、6 个时段，并显示成功、重复跳过和过期跳过结果。库存编辑保留并发校验；诊疗与配药操作以服务器返回状态为准。

## 构建

```powershell
Set-Location .\admin-web
npm ci
npm run build
npm run preview
```

构建产物位于 `admin-web/dist/`。本地预览默认使用 `http://127.0.0.1:4173`。正式部署时，Web 服务应将 `/api` 和 `/uploads` 转发到后端，并将页面路由回退到 `index.html`。

更多安装与公开仓库注意事项见 [首次安装与 GitHub 上传](../docs/首次安装与GitHub上传.md)。
